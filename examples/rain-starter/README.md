# 雨课堂 HeroUI：独立消费者示例

这个最小 React / Vite 示例使用仓库内的三个 r2 安装包，不依赖本地组件源码链接。`App.tsx`、`App.styles.ts`、挂载入口与 HTML 复制自冻结 r2 示例；全局样式补齐宿主正文色继承，未改主题值或组件交互。

## 启动

先克隆或下载**整个仓库**，保留 `delivery/` 与 `examples/` 的相对位置。使用 Node.js 22.14 或更新版本，然后在本目录运行：

```sh
npm install
npm run dev
```

终端会输出本机预览地址，默认是 <http://127.0.0.1:5173/>。如果端口已占用，以实际输出为准。不要只下载这个文件夹：`package.json` 中的三个 `file:` 依赖需要仓库内的 `.tgz`。

该目录是独立 npm 应用，不属于根目录的 pnpm workspace；不需要先安装或构建整套文档站。安装会从 npm 获取清单中明确声明的 React 19、React Aria、Tailwind 4、Vite 等依赖；三个改造组件／样式／主题包则来自本仓库的冻结归档。

## 内容与主题

页面组合 Card、Tabs、Table、表单与 Modal。所有数据都是虚构的页内状态，不发送成绩或请求业务服务。雨课堂标记位于 `index.html` 的 html 根节点，body 和 portal 同时继承；移除 `data-rain-theme` 可撤销 Rain 覆盖，但这个最小示例不增加主题切换控制器。

`global.css` 使用主题语义变量绑定正文色与字体，没有硬编码品牌色。要接入现有项目，可按 [r2 接入说明](../../delivery/rain-heroui-local-2026-10-20-r2/README.md) 复制所需内容，避免替换业务框架或路由。
