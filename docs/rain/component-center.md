## 维护方式

```sh
pnpm local:catalog
pnpm local:catalog:check
```

前者先刷新 `inventory.json`，再生成 `apps/docs/src/generated/rain-catalog.json` 与 `docs/rain/ai/components.md`；后者只比较源内容与生成结果，不运行构建或浏览器回归。界面读取精简目录，不加载全库组件预览。

新增 UI 源码位于 `apps/docs/src/components/rain-center/`，目录生成器位于 `scripts/rain/catalog.mjs`。中英文 MDX 复用同一套目录界面。

本地启动器输出组件中心地址，并将 `RAIN_STORYBOOK_PORT` 推导到 `NEXT_PUBLIC_RAIN_STORYBOOK_URL`；独立启动文档时可设置该公开 URL。Storybook Welcome 的链接仍使用默认文档端口 3100，自定义端口按启动器地址访问。

## 入口复查（2026-10-20）

证据：`evidence/runtime/rain-center-flow-check-2026-10-20/`。本轮修复：

- SwitchGroup、Header 等关联条目原先会直接选父文档前三个示例，可能没有使用该组件；现在只提供实际引用当前模块的示例，再取最多三个。自有文档的选例策略保留。
- 英文页面复制上下文原先固定使用中文文档／示例；现在文案和资料跟随当前语言。英文搜索提示也改为实际可命中的「模态框」。
- 复制失败会清除旧的成功标记，并在当前条目显示完整只读上下文供手动复制。修改搜索、分类或清除筛选时会清理复制提示；过期的异步复制结果不能重新写回提示。
- 保存原版深色后，预览链接原先会产生服务端浅色／客户端深色的 hydration 属性差异；现在复用现有 `useIsMounted`，首次内容一致，页面就绪后同步保存的主题。
