## 根据目标选择修改位置

| 目标 | 入口 |
| --- | --- |
| 业务页面、卡片、面板重组 | 业务组合层；可参考 `apps/docs/src/components/rain-examples/grading-panel/` |
| 统一品牌色、字体族、圆角 | `packages/rain-theme/index.css` |
| 需要复用的业务交互 | 先复用现有组合，再抽取真实重复的部分 |
| 基础组件能力不足 | 阅读对应 `packages/react` 源码，记录最小修改及受影响状态 |

课堂练习批改页已经用户审核，当前按钮圆角为 10px；[打开这个组合示例](/docs/react/examples/grading-panel)。示例使用虚构数据，草稿与模拟提交仅存在于当前页面。

用户本次还限定确认当前表格背景 `#EBEFFF`、表头文字 `#7485A8`，以及普通 Tabs 名称单行、省略和悬停原生全名提示；不包括任意富文本自定义标签、全库所有状态或生产验收。

## 保持当前边界

沿用本仓库固定版本，不混用旧 NextUI/v2 API。主题集中维护，不把品牌数值散写到页面，不为全部组件添加空包装。

当前继续采用轻量检查，暂不运行新的全库重测试或文档／Storybook 生产构建。r2 的私有归档已完成本轮限定消费验证，不是沿用旧交付结果；定向编译仅替换授权的 Tabs 产物并保留共享模块。接入说明、实际消费与浏览器范围见本地 `docs/rain/consumer-verification.md`；本次复用本机既有第三方依赖，结果针对前端 Bundler，不是全新联网安装、全库行为或生产验收。
