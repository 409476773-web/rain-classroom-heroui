## Choose where to edit

| Goal | Entry |
| --- | --- |
| Recompose pages, cards and panels | The business layer; see `apps/docs/src/components/rain-examples/grading-panel/` |
| Change brand colors, font families or radii | `packages/rain-theme/index.css` |
| Reuse a business interaction | Extract a shared composition after repetition exists |
| Extend a primitive API | Read its `packages/react` implementation and record affected states |

It does not cover arbitrary custom rich-text labels, every library state or production acceptance.

Use the pinned v3 API; avoid legacy NextUI/v2 patterns and empty wrappers for every component. Keep theme values centralized.

The current workflow uses focused checks. New heavy regression runs and documentation/Storybook production builds remain deferred.
